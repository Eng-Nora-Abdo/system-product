# 🛒 Product Management System (Full Stack CRUD System)

نظام متكامل لإدارة المنتجات مبني كـ **Full Stack Application** يجمع بين واجهة أمامية حديثة وسريعة الاستجابة (Frontend) وخادم خلفي متكامل (Backend REST API) مع قاعدة بيانات لحفظ وتحديث المنتجات.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

### 🖥️ الفرونت إند (Frontend):
- **HTML5 & CSS3**
- **Bootstrap 5** لتصميم متجاوب وعصري مع الشاشات المختلفة.
- **Font Awesome 6** لأيقونات جذابة وواضحة.
- **Vanilla JavaScript (ES6+)** مع **Fetch API** للتواصل غير المتزامن مع السيرفر.

### ⚙️ الباك إند (Backend):
- **Node.js**
- **Express.js** لبناء الـ RESTful API وتخديم ملفات الفرونت إند.
- **CORS** للسماح بتبادل البيانات بأمان.

### 💾 قاعدة البيانات (Database):
- نظام تخزين واسترجاع بيانات متكامل بصيغة JSON (`data/products.json`) لضمان حفظ البيانات بشكل دائم بدون الحاجة لتثبيت خوادم قواعد بيانات خارجية معقدة.
- يدعم أيضاً العمل بالـ **LocalStorage** كوضع احتياطي تلقائي (Offline Fallback) لو تم فتح الموقع دون تشغيل السيرفر.

---

## ✨ المميزات الرئيسية (Key Features)

1. **العمليات الأساسية (CRUD Operations):**
   - **إضافة منتج (Create):** حفظ المنتج في قاعدة البيانات وعرضه مباشرة.
   - **عرض المنتجات (Read):** ترقيم المنتجات تصاعدياً (بدءاً من 1)، مع عرض التكلفة، التصنيف، والوصف.
   - **تعديل منتج (Update):** تعديل أي منتج مع زر **Cancel** لإلغاء التعديل والرجوع للوضع الافتراضي.
   - **حذف منتج (Delete):** تأكيد مسبق لمنع الحذف غير المقصود.
   - **حذف الكل (Delete All):** زر لمسح كافة المنتجات بضغطة واحدة مع تحديث العداد.

2. **التحقق اللحظي من المدخلات (Live Form Validation):**
   - التحقق من اسم المنتج (يقبل حروف كبيرة وصغيرة وأرقام واللغة العربية من 2 إلى 30 حرف).
   - التحقق من السعر (أرقام موجبة حتى 100,000 مع دعم الكسور).
   - التحقق من التصنيف والوصف.
   - علامات توضيحية من Bootstrap (`is-valid` / `is-invalid`) مع رسائل خطأ واضحة.

3. **البحث الذكي وتظليل النتائج (Search & Match Highlighting):**
   - بحث فوري وسريع في **اسم المنتج** و**التصنيف**.
   - تظليل الحروف المطابقة بلون مميز لسهولة الوصول للبيانات.
   - زر لمسح البحث بضغطة واحدة.

4. **مؤشر حالة الاتصال بالسيرفر (Hybrid Status Indicator):**
   - يعرض مؤشراً في أعلى الصفحة يوضح ما إذا كان التطبيق متصلاً بالسيرفر وقاعدة البيانات (`Full Stack Mode`) أو يعمل بالوضع المحلي (`LocalStorage Mode`).

## 🛠️ طريقة تشغيل المشروع محلياً (How to Run)

### 1. تثبيت الحزم (مرة واحدة فقط):
```bash
npm install
```

### 2. تشغيل السيرفر:
```bash
npm start
```

### 3. فتح الموقع:
افتح المتصفح وتوجه إلى:
👉 **http://localhost:3000**

## 📡 مسارات الـ API (RESTful API Endpoints)

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | فحص حالة عمل السيرفر |
| `GET` | `/api/products` | جلب جميع المنتجات (أو البحث عبر `?q=keyword`) |
| `GET` | `/api/products/:id` | جلب تفاصيل منتج محدد عبر رقمه التعريفي |
| `POST` | `/api/products` | إضافة منتج جديد |
| `PUT` | `/api/products/:id` | تعديل منتج حالي |
| `DELETE` | `/api/products/:id` | حذف منتج محدد |
| `DELETE` | `/api/products` | حذف جميع المنتجات من قاعدة البيانات |
